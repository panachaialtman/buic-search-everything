KNOWN / NON-BLOCKING LIMITATIONS
1. The Faculty/Major audit is intentionally conservative. A Source wording review flag means the row was not contradicted by checked BU sources, but the exact EN/TH label was not proven from an exact current official program/curriculum source. Do not convert those rows to Official automatically.
2. Some official BU pages use source-specific or intake-specific naming. Preserve source context and academic year rather than forcing one normalized name across all historical students.
3. Excel import still loads SheetJS from a CDN and can fail offline. Bundled data remains offline-capable.
4. Excel rollback history uses browser localStorage. Large imported workbooks may reach the browser storage quota; the app handles this by warning and continuing without another backup.
5. Create Folder still relies on Chromium File System Access API and user-granted write permission.
6. styles.css still contains older version override sections. V4.6 adds final reliability overrides, but a future module/stylesheet consolidation remains worthwhile.
7. app.js remains a single large application file. Feature modules would improve maintainability in a later engineering refactor.
